Ship a shadcn-compatible component registry served from the docs site.

Three production-ready Tailwind components installable via the shadcn CLI:

```bash
npx shadcn@latest add https://riyal.js.org/r/riyal-price-tag.json
npx shadcn@latest add https://riyal.js.org/r/riyal-amount-input.json
npx shadcn@latest add https://riyal.js.org/r/riyal-checkout-summary.json
```

- **`riyal-price-tag`** — Tailwind-styled SAR price label with size (`sm`/`md`/`lg`/`xl`) and tone (`default`/`muted`/`emerald`/`primary`) variants. Wraps `<RiyalPrice>` from `riyal/react` with a `vatIncluded` / `showVatLabel` toggle.
- **`riyal-amount-input`** — Form-grade SAR input with label, hint, and error states. Uses the masked `<RiyalInput mask />` so paste of `"SAR 2,499.99"`, `"⃁ 2,499.99"`, or `"٢٤٩٩٫٩٩"` all yield a clean number. Generates a stable `id`, wires `aria-invalid` / `aria-describedby`, and styles the wrapper with `focus-within` ring + destructive-state ring.
- **`riyal-checkout-summary`** — Receipt-style block (subtotal, discount, shipping, VAT, grand total) built on `cartTotal` from `riyal/cart` and `<RiyalPrice>` from `riyal/react`.

Each item drops a `.tsx` file into `components/riyal/` in the consumer's project so they own the source, and pulls `riyal` as an npm dependency for the underlying glyph, formatting, masking, and cart helpers.

The registry lives at `apps/docs/public/r/` and is generated by `apps/docs/registry/build.mjs` — wired into `pnpm --filter @riyal/docs dev` and `build` so JSONs stay in sync. Registry index: `https://riyal.js.org/r/registry.json`.
